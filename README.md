# Sciqus Redesign

A modern responsive redesign of the Sciqus AMS website focused on improving user experience, visual hierarchy, responsiveness, and overall SaaS product presentation.

## 🚀 Overview

This project is a frontend redesign case study of the original Sciqus AMS marketing website. The redesign focuses on creating a cleaner, more modern, and conversion-oriented user experience while preserving the core product messaging and brand identity.

The project was built using pure HTML, CSS, and JavaScript with a strong focus on:

* Responsive design
* UI/UX improvements
* Modern SaaS aesthetics
* Better content structure
* Improved visual hierarchy
* Reusable frontend architecture

---

## ✨ Features

* Fully responsive layout
* Modern SaaS-inspired UI
* Interactive sliders/carousels
* Mobile-friendly navigation
* Smooth animations & transitions
* Reusable UI components
* Improved typography system
* Better spacing and layout consistency
* Modern footer & CTA sections
* Optimized visual hierarchy
